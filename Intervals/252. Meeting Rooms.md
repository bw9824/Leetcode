# 252. Meeting Rooms
difficulty: `easy`
tags: #Array  #Sorting   #QuickSort

### Problem
You are given an array of meeting times `intervals` where `intervals[i] = [starti, endi]`.

A person can attend all meetings if no two meeting intervals overlap. Meetings ending at time `t` and starting at time `t` **do not** overlap.

​​​​​​​Return `true` if a person can attend all meetings. Otherwise, return `false`.

```
Example 1:
Input: intervals = [[0,30],[5,10],[15,20]]
Output: false
```

### Note
qsort(intervals, intervalsSize, sizeof(int*), cmp)
- The four arguments are: the array, number of element, size of element, how to compare two elements.
- sizeof(int*) : Because intervals is an array of pointers. Each element qsort moves around is one int* (8 bytes on 64-bit), each pointing to a 2-element row.
int cmp(const void* a, const void* b)
- qsort hands you a pointer _to an array element_. Since each element is itself an `int*`, `a` is really an `int**` — so you cast it and dereference once to get the actual row pointer. Then `x[0]` is that interval's start time.
- qsort needs a **negative / zero / positive** result. Comparison (> or <) only gives 1 or 0, so this (x[0] > y[0]) - (x[0] < y[0]) gives `-1`, `0`, or `1`. Comparing instead of subtracting (x[0] - y[0]) avoids overflow (large positive minus a large negative) entirely. Ex: return 1 x is following y.
### Solution
```c =
int cmp(const void* a, const void* b) {
    int* x = *(int**)a;
    int* y = *(int**)b;
    return (x[0] > y[0]) - (x[0] < y[0]);  // compare by start time, avoids overflow
}

bool canAttendMeetings(int** intervals, int intervalsSize, int* intervalsColSize) {
    
    if (intervalsSize <= 1) return true;

    qsort(intervals, intervalsSize, sizeof(int*), cmp);

    for (int i = 1; i < intervalsSize; i++) {
        // this meeting starts before the previous one ends -> overlap
        if (intervals[i][0] < intervals[i-1][1]) 
            return false;
    }
    return true;
}
```
