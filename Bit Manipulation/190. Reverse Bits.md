### Problem
Reverse bits of a given 32 bits signed integer.

```
Example 1:
Input: n = 43261596

Output: 964176192
```

### Solution
```c =
int reverseBits(int n) {
    int result = 0;

    for (int i = 0; i < 32; i++) {
        result <<= 1;
        result |= (n & 1);
        n >>= 1;
    }

    return result;
}
```
