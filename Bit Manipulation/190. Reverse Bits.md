# 190. Reverse Bits
difficulty: `easy`
tags: #BitManipulation #DivideAndConquer

### Problem
Reverse bits of a given 32 bits signed integer.
```
Example 1:
Input: n = 43261596
Output: 964176192
```

### Note
```
n is unsigned int so that >> is a logical shift (zero-fill) — an arithmetic shift on a signed value would smear the sign bit and corrupt the result. The int return type just matches LeetCode's signature; that final implicit conversion leaves the bit pattern untouched and only reinterprets it as signed, so the value may come out negative while the bits are identical.

When using `unsigned`, pad with 0; when using `signed` and the value is negative, pad with 1.
```

### Solution
```c =
int reverseBits(int n) {
    int ans = 0;
    for (int i=0; i<32; i++){
        ans = (ans << 1) | (n & 1);
        n >>= 1;
    }
    return ans;
}
```

### Complexity — Time / Space: O(1)

### Edge Cases

### Issue & Fix
Issue: If you had to process millions of these integers, how could you use a lookup table to speed things up?
Fix: Divide-and-conquer: each line swaps two equal-sized halves of a block using a mask to isolate them and shifts to swap their positions — first 16-bit halves, then 8-bit, 4-bit, 2-bit, and finally single bits. Since 32 = 2⁵, exactly 5 halving steps fully reverse all the bits.

|                | Bits                                 |
| -------------- | ------------------------------------ |
| Original       | a b c d  e f g h                     |
| Exchange 4-bit | e f g h \| a b c d                   |
| Exchange 2-bit | g h \| e f \| c d \| a b             |
| Exchange 1-bit | h \| g \| f \| e \| d \| c \| b \| a |

### Solution 2
```c
int reverseBits(unsigned int  n) { // When using `unsigned`, pad with 0; when using `signed` and the value is negative, pad with 1.
    n = (n >> 16) | (n << 16);
    n = ((n & 0xff00ff00) >> 8) | ((n & 0x00ff00ff) << 8);
    n = ((n & 0xf0f0f0f0) >> 4) | ((n & 0x0f0f0f0f) << 4);
    n = ((n & 0xcccccccc) >> 2) | ((n & 0x33333333) << 2);
    n = ((n & 0xaaaaaaaa) >> 1) | ((n & 0x55555555) << 1);
    return n;
}
```
