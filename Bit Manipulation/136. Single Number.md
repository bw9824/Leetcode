# 136. Single Number
difficulty: `easy`
tags: #Array #BitManipulation

### Problem
Given a **non-empty** array of integers `nums`, every element appears _twice_ except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

```
Example 1:
Input: nums = [4,1,2,1,2]

Output: 4
```

### Note
```
(Hint) XOR
AND: It is true only when both are true.
OR:  It is true only if either one is true.
XOR: It is true only when one is true.
=> "A number appearing twice" will always be 0 after XOR. Then we can get the single one.
```

### Solution
```c =
int singleNumber(int* nums, int numsSize) {
    int result = nums[0];
    
    for(int i=1; i<numsSize; i++){
        result^=nums[i];
    }

    return result;
}
```

### Complexity — Time / Space: O(N)


### Edge Cases:


### Issue & Fix
Issue: What if numsSize is 0, then nums[0] is out of boundary
Fix: 0 ^ x = x

### Solution 2
```c
int singleNumber(int* nums, int numsSize) {
    int result = 0;              // XOR identity: 0 ^ x == x
    for (int i = 0; i < numsSize; i++) {
        result ^= nums[i];
    }
    return result;
}
```
