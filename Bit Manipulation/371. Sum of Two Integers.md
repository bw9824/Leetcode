# 371. Sum of Two Integers
difficulty: `medium`
tags: #Math  #BitManipulation 

### Problem
Given two integers a and b, return the sum of the two integers without using the operators + and -.

```
Example 1:
Input: a = 1, b = 2
Output: 3
```

### Solution
```c =
int getSum(int a, int b) {

    while (b!=0){
	    // Cast to unsigned before shifting: if a&b's sign bit (bit 31) is set, 
	    // left-shifting it as a signed int is undefined behavior in C. 
	    // Shifting as unsigned guarantees a well-defined logical shift.
        int carry = (int)((unsigned int)(a&b)<<1); // AND finds where carries occur, and the left shift moves each carry to its correct bit position
        
        a = a^b; // XOR computes the sum without carries
        b = carry;
    }
    return a;
}
```
