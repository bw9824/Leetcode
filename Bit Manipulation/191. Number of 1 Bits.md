# 191. Number of 1 Bits
difficulty: `easy`
tags: #BitManipulation #DivideAndConquer

### Problem
Given a positive integer n, write a function that returns the number of set bits in its binary representation (also known as the Hamming weight).
```
Example 1:
Input: n = 11

Output: 3

Explanation:

The input binary string 1011 has a total of three set bits.
```

### Note
```
n &= n - 1:
n-1 flips the lowest 1 to 0, and everything right of it to 1s. ANDing with n cancels just that one bit — so each call removes exactly one 1.
```

### Solution
```c =
int hammingWeight(int n) {
    
    int result=0;
    while(n>0){
        if (n&1){
            result++;
        }
        n>>=1;
    }
    return result;
}
```
### Complexity — Time / Space: O(logN)

### Edge Cases
None
### Issue & Fix
Issue: Can we skip the zeros ?
Fix: The Brian Kernighan algorithm (n &= n - 1) to iterate only over the set bits, further improving efficiency.

### Solution 2
```c =
int hammingWeight(int n) {
    
    int result = 0;
    while (n != 0){      // != 0, It can also use for negative
        n&=(n-1);
        result++;
    }
    return result;
}
```
### Complexity — Time / Space: O(number of set bits)
