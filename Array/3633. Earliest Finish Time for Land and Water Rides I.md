# 3633. Earliest Finish Time for Land and Water Rides I
difficulty: `easy`
tags: #MidLevel #Array #TwoPointers #BinarySearch #Greedy #Sorting #BiweeklyContest162

### Problem
You are given two categories of theme park attractions: **land rides** and **water rides**.

- **Land rides**
    - `landStartTime[i]` – the earliest time the `ith` land ride can be boarded.
    - `landDuration[i]` – how long the `ith` land ride lasts.
- **Water rides**
    - `waterStartTime[j]` – the earliest time the `jth` water ride can be boarded.
    - `waterDuration[j]` – how long the `jth` water ride lasts.

A tourist must experience **exactly one** ride from **each** category, in **either order**.

- A ride may be started at its opening time or **any later moment**.
- If a ride is started at time `t`, it finishes at time `t + duration`.
- Immediately after finishing one ride the tourist may board the other (if it is already open) or wait until it opens.

Return the **earliest possible time** at which the tourist can finish both ride

```
Example 1:
Input: landStartTime = [2,8], landDuration = [4,1], waterStartTime = [6], waterDuration = [3]

Output: 9

Plan A (land ride 0 → water ride 0):
Start land ride 0 at time landStartTime[0] = 2. Finish at 2 + landDuration[0] = 6.
Water ride 0 opens at time waterStartTime[0] = 6. Start immediately at 6, finish at 6 + waterDuration[0] = 9.

Plan B (water ride 0 → land ride 1):
Start water ride 0 at time waterStartTime[0] = 6. Finish at 6 + waterDuration[0] = 9.
Land ride 1 opens at landStartTime[1] = 8. Start at time 9, finish at 9 + landDuration[1] = 10.

Plan C (land ride 1 → water ride 0):
Start land ride 1 at time landStartTime[1] = 8. Finish at 8 + landDuration[1] = 9.
Water ride 0 opened at waterStartTime[0] = 6. Start at time 9, finish at 9 + waterDuration[0] = 12.

Plan D (water ride 0 → land ride 0):
Start water ride 0 at time waterStartTime[0] = 6. Finish at 6 + waterDuration[0] = 9.
Land ride 0 opened at landStartTime[0] = 2. Start at time 9, finish at 9 + landDuration[0] = 13.

Plan A gives the earliest finish time of 9.
```

### Note
```
Solution 1:
Max (land/water Start Time + land/water Duration, water/land Start Time) + water/land Duration

```

### Solution 1
```c =
int compareMax (int a, int b){
    if (a>b){
        return a;
    }
    else{
        return b;
    }
}
int compareMin (int a, int b){
    if (a<b){
        return a;
    }
    else{
        return b;
    }
}

int earliestFinishTime(int* landStartTime, int landStartTimeSize, int* landDuration, int landDurationSize, int* waterStartTime, int waterStartTimeSize, int* waterDuration, int waterDurationSize) {
    
    int result = landStartTime[0]+landDuration[0]+waterStartTime[0]+waterDuration[0];
    for (int i = 0; i < landStartTimeSize; i++){
        for (int j = 0; j < waterStartTimeSize; j++){
            // land to water
            result = compareMin(compareMax(landStartTime[i] + landDuration[i], waterStartTime[j]) + waterDuration[j], result);
            // water to land
            result = compareMin(compareMax(waterStartTime[j] + waterDuration[j], landStartTime[i]) + landDuration[i], result);
        }
    }
    return result;
}
```

### Complexity — Time / Space: O(N×M)


### Edge Cases:
Initial result = INT_MAX, landStartTime[0]+landDuration[0]+waterStartTime[0]+waterDuration[0] may out of boundary.

### Issue & Fix
Issue: Is it necessary to compare all result ? There should be a better solution
Fix: Find the least (start time + duration) of each land and water, then compare with the other start time

### Solution 2
```c
int earliestFinishTime(int* landStartTime, int landStartTimeSize, int* landDuration, int landDurationSize, int* waterStartTime, int waterStartTimeSize, int* waterDuration, int waterDurationSize) {
        int n = landStartTimeSize, m = waterStartTimeSize;

    // Earliest you can be done with ANY land ride (nothing blocks the first ride)
    int bestLandFinish = INT_MAX;
    for (int i = 0; i < n; i++) {
        int f = landStartTime[i] + landDuration[i];
        if (f < bestLandFinish) bestLandFinish = f;
    }
    // Same for water
    int bestWaterFinish = INT_MAX;
    for (int j = 0; j < m; j++) {
        int f = waterStartTime[j] + waterDuration[j];
        if (f < bestWaterFinish) bestWaterFinish = f;
    }

    int ans = INT_MAX;

    // Order 1: land first, then water.
    // The water ride can't start before its own startTime, nor before land is done.
    for (int j = 0; j < m; j++) {
        int s = waterStartTime[j] > bestLandFinish ? waterStartTime[j] : bestLandFinish;
        int f = s + waterDuration[j];
        if (f < ans) ans = f;
    }

    // Order 2: water first, then land.
    for (int i = 0; i < n; i++) {
        int s = landStartTime[i] > bestWaterFinish ? landStartTime[i] : bestWaterFinish;
        int f = s + landDuration[i];
        if (f < ans) ans = f;
    }

    return ans;
}
```
### Complexity — Time / Space: O(N+M)
