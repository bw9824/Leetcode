# 217. Contains Duplicate
difficulty: `easy`
tags: #Array #HashTable  #Sorting 

### Problem
Given an integer array `nums`, return `true` if any value appears **at least twice** in the array, and return `false` if every element is distinct.

```
Example 1:
Input: nums = [1,2,3,1]
Output: true

Explanation:
The element 1 occurs at the indices 0 and 3.
```

### Note
```
Hash table = calculate the position directly, instead of searching for it.

Like lockers: your name → a quick calculation → a locker number. Next time, same calculation, same locker — no searching needed. That's what makes lookups fast
```

### Solution
```c =
bool containsDuplicate(int* nums, int numsSize) {
    int tableSize = numsSize * 2 + 1;
    int* table = (int*)malloc(tableSize * sizeof(int)); // array default value random
    bool* used = (bool*)calloc(tableSize, sizeof(bool)); // array default value 0

    for (int i = 0; i < numsSize; i++) {
        int h = ((nums[i] % tableSize) + tableSize) % tableSize;
        while (used[h]) {           // if the index been used
            if (table[h] == nums[i]) {
                free(table);
                free(used);
                return true;
            }
            h = (h + 1) % tableSize; // find another index to save nums[i]
        }
        table[h] = nums[i]; // save nums[i] in table[h]
        used[h] = true; // num[i] may be 0, so we need flags
    }

    free(table);
    free(used);
    return false;
}
```
