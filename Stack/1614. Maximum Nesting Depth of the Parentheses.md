# 1614. Maximum Nesting Depth of the Parentheses
difficulty: `easy`
tags: #MidLevel #String #Stack #BracketSequences

### Problem
Given a **valid parentheses string** `s`, return the **nesting depth** of `s`. The nesting depth is the **maximum** number of nested parentheses.

```
Example 1:
Input: s = "(1+(2*3)+((8)/4))+1"
Output: 3

Explanation:
Digit 8 is inside of 3 nested parentheses in the string.
```

### Solution
```c =
int maxDepth(char* s) {
    int len = strlen(s);
    int temp = 0, max = 0;
    
    for (int i = 0; i<len; i++){
        if(s[i]=='('){
            temp++;
        }
        else if(s[i]==')'){
            temp--;
        }

        if(temp>max){
            max=temp;
        }
    }

    return max;
}
```
