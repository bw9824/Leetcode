# 20. Valid Parentheses
difficulty: `easy`
tags: #Stack #String #BracketSequences

### Problem
Given a string `s` containing just the characters `'('`, `')'`, `'{'`, `'}'`, `'['` and `']'`, determine if the input string is valid.

An input string is valid if:

1. Open brackets must be closed by the same type of brackets.
2. Open brackets must be closed in the correct order.
3. Every close bracket has a corresponding open bracket of the same type.

```
Example 1:
Input: s = "([])"
Output: true

Example 2:
Input: s = "([)]"
Output: false
```

### Note
```
malloc(), free(): Dynamically allocated memory will not be automatically returned before the program ends; you must use `free` to release the memory.


Stack = a stack of plates: you can only add or remove from the **top**. Last one in is the first one out (LIFO).
```

### Solution
```c =
bool isValid(char* s) {
    int n = strlen(s);
    if (n % 2 != 0) return false;  // odd length can never be valid, exit early

    char* stack = (char*)malloc(n * sizeof(char));
    int top = 0;

    for (int i = 0; i < n; i++) {
        if (s[i] == '(' || s[i] == '{' || s[i] == '[') {
            stack[top++] = s[i];  // opening bracket, push onto the stack
        } else {
            // closing bracket: check the stack isn't empty, and that it matches
            // top == 0, for the example: "){" for exit early
            if (top == 0 ||
                (s[i] == ')' && stack[top - 1] != '(') ||
                (s[i] == '}' && stack[top - 1] != '{') ||
                (s[i] == ']' && stack[top - 1] != '[')) {
                free(stack);
                return false;
            }
            top--;  // matched successfully, pop it off
        }
    }

    bool result = (top == 0);  // stack must be empty for the string to be valid
    free(stack);
    return result;
}
```

### Complexity — Time / Space: O(N)


### Edge Cases:
strlen(n) must be even
