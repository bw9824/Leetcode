# 73. Set Matrix Zeroes
difficulty: `medium`
tags: #Array  #HashTable  #Matrix 

### Problem
Given an `m x n` integer matrix `matrix`, if an element is `0`, set its entire row and column to `0`'s.

You must do it [in place](https://en.wikipedia.org/wiki/In-place_algorithm).

```
Example 1:
Input: matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

### Note

### Solution
```c =
void setZeroes(int** matrix, int matrixSize, int* matrixColSize) {
    int rows = matrixSize, cols = * matrixColSize;
    bool* zeroRow = (bool*)calloc(rows, sizeof(bool));
    bool* zeroCol = (bool*)calloc(cols, sizeof(bool));

    // First pass: record which rows and columns need zeroing
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (matrix[i][j] == 0) { 
                zeroRow[i] = true; 
                zeroCol[j] = true; 
            }
        }
    }
    // Second pass: apply
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (zeroRow[i] || zeroCol[j]) {
                matrix[i][j] = 0;
            }
        }
    }

    free(zeroRow); 
    free(zeroCol);
}
```

### Complexity — Time / Space: O(M×N)
