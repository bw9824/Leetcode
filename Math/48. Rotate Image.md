# 48. Rotate Image
difficulty: `medium`
tags: #Math #Array #Matrix

### Problem
You are given an n x n 2D matrix representing an image, rotate the image by 90 degrees (clockwise).

You have to rotate the image in-place, which means you have to modify the input 2D matrix directly. DO NOT allocate another 2D matrix and do the rotation.

```
Example 1:
Input: matrix = [[1,2,3],[4,5,6],[7,8,9]]
Output: [[7,4,1],[8,5,2],[9,6,3]]
```

### Note
**Original :**
```
1  2  3
4  5  6
7  8  9
```

**Step 1 :**

```
1  4  7
2  5  8
3  6  9
```

**Step 2 :**

```
7  4  1
8  5  2
9  6  3
```

### Solution
```c =
void rotate(int** matrix, int matrixSize, int* matrixColSize) {
    // Step 1: transpose — swap matrix[i][j] with matrix[j][i]
    for (int i = 0; i < matrixSize; i++) {
        for (int j = i + 1; j < matrixSize; j++) {
            int temp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = temp;
        }
    }
    // Step 2: reverse each row (left-right flip)
    for (int i = 0; i < matrixSize; i++) {
        for (int left = 0, right = matrixSize - 1; left < right; left++, right--) {
            int temp = matrix[i][left];
            matrix[i][left] = matrix[i][right];
            matrix[i][right] = temp;
        }
    }
}
```

### Issue & Fix
Issue: Two for loop. Can we make it one ?
Fix: Each time, four corresponding positions are processed, and a single move places all four elements into their correct final positions—each element is read and written only once. Complexity — Time / Space: The same

|              | Code                 |
| ------------ | -------------------- |
| Top left     | matrix[i][j]         |
| Top right    | matrix[j][n-i-1]     |
| bottom right | matrix[n-i-1][n-j-1] |
| bottom left  | matrix[n-j-1][i]     |
i < (n+1)/2: Process the top half of the columns (including the middle column if the number of rows is odd).
j < n/2: Process the left half of the rows (excluding the middle row if the number of rows is odd).
### Solution 2
```c
void rotate(int** matrix, int matrixSize, int* matrixColSize) {
    int n = matrixSize;
    for (int i = 0; i < (n+1) / 2; i++) {
        for (int j = 0; j < n / 2; j++) {
            int temp = matrix[n-j-1][i];
            matrix[n-j-1][i] = matrix[n-i-1][n-j-1];
            matrix[n-i-1][n-j-1] = matrix[j][n-i-1];
            matrix[j][n-i-1] = matrix[i][j];
            matrix[i][j] = temp;
        }
    }
}
```
