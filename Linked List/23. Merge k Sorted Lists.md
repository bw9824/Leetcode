# 23. Merge k Sorted Lists
difficulty: `hard`
tags: #LinkedList #DivideAndConquer #Heap #MergeSort #TournamentSort

### Problem
You are given an array of `k` linked-lists `lists`, each linked-list is sorted in ascending order.

_Merge all the linked-lists into one sorted linked-list and return it._

```
Example 1:
Input:  
Output: [1,1,2,3,4,4,5,6]
Explanation: The linked-lists are:
[
  1->4->5,
  1->3->4,
  2->6
]
merging them into one sorted linked list:
1->1->2->3->4->4->5->6
```

### Solution
```c =
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */

static struct ListNode* mergeTwoLists(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode dummy;
    struct ListNode* pre = &dummy;
    while (l1 != NULL && l2 != NULL) {
        if (l1->val > l2->val) { 
            pre->next = l2; 
            l2 = l2->next; 
        }
        else { 
            pre->next = l1; 
            l1 = l1->next; 
        }
        pre = pre->next;
    }
    pre->next = (l1 == NULL) ? l2 : l1;
    return dummy.next;
}

struct ListNode* mergeKLists(struct ListNode** lists, int listsSize) {
    if (listsSize == 0) return NULL;

    // Pair up lists and merge them, halving the count each round:
    // k lists -> k/2 -> k/4 -> ... -> 1
    while (listsSize > 1) {
        int newSize = 0;
        for (int i = 0; i < listsSize; i += 2) {
            if (i + 1 < listsSize) {
                lists[newSize++] = mergeTwoLists(lists[i], lists[i + 1]);
            } else {
                lists[newSize++] = lists[i];   // odd one out, carry it forward
            }
        }
        listsSize = newSize;
    }
    return lists[0];

}
```
