# 143. Reorder List
difficulty: `easy`
tags: #LinkedList #TwoPointers  #Stack #Recursion 

### Problem
You are given the head of a singly linked-list. The list can be represented as:

L0 → L1 → … → Ln - 1 → Ln

_Reorder the list to be on the following form:_

L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …

You may not modify the values in the list's nodes. Only nodes themselves may be changed.

```
Example 1:
Input: head = [1,2,3,4,5]
Output: [1,5,2,4,3]
```

### Solution
```c =
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
void reorderList(struct ListNode* head) {
    if (head == NULL || head->next == NULL) return;

    // Step 1: find the middle with slow/fast pointers.
    // slow ends up at the last node of the first half.
    struct ListNode* slow = head;
    struct ListNode* fast = head;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    // Step 2: reverse the second half, and cut it off from the first.
    struct ListNode* second = slow->next;  // Second half
    slow->next = NULL;              // split the list in two
    struct ListNode* prev = NULL;  // Inital reverse list
    while (second != NULL) {
        struct ListNode* nxt = second->next;
        second->next = prev;        // flip the arrow backwards
        prev = second;
        second = nxt;
    }
    second = prev;                  // prev is now the head of the reversed half

    // Step 3: weave the two halves together, alternating nodes.
    struct ListNode* first = head;
    while (second != NULL) {
        struct ListNode* f_next = first->next;
        struct ListNode* s_next = second->next;
        first->next = second;
        second->next = f_next;
        first = f_next;
        second = s_next;
    }
}
```
