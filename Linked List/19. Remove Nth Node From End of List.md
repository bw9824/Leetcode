# 19. Remove Nth Node From End of List
difficulty:  `medium`
tags: #LinkedList  #TwoPointers

### Problem
Given the `head` of a linked list, remove the `nth` node from the end of the list and return its head.

```
Example 1:
Input: head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
```

### Note
Why are dummy nodes needed?

If the first node to be deleted (n == string length) has no "previous node" to take over, then adding a dummy node before the head ensures the first node has a predecessor.
Finally, `dummy.next` is returned instead of `head`, because `head` might have already been deleted.
The dummy node uses a locale variable (`struct ListNode dummy;`) instead of `malloc`, saving on configuration and deallocation, and is automatically garbage collected when the function ends.


### Solution
```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    struct ListNode dummy;
    dummy.next = head;

    struct ListNode* fast = &dummy;
    struct ListNode* slow = &dummy;

    // move fast n steps ahead, so the gap between them is n
    for (int i = 0; i < n; i++) {
        fast = fast->next;
    }

    // walk both until fast hits the last node
    // slow then sits right before the node to delete
    while (fast->next != NULL) {
        fast = fast->next;
        slow = slow->next;
    }

    struct ListNode* target = slow->next;
    slow->next = target->next;
    free(target);

    return dummy.next;
}
```
